# 星空 SPACE · 界面图片素材

本仓库保存《星空SPACE》的生成图片，供界面按原图链接加载。

- `opening-horizon-v2.png`：行星地平线与日出开场背景。
- `hulls-micro-v2.png`、`hulls-small-v2.png`、`hulls-medium-v2.png`、`hulls-large-v2.png`、`hulls-giant-v3.png`：五种船体尺寸的线稿图集，共 40 个外观设计。
- `asset-index.json`：原图文件、尺寸、SHA-256 和每艘船的图集位置。

每张船体图集均为四列两行：第一行依次为通用船、运输船、游轮、采矿船；第二行为工程船、探索船、猎船、突击船。各图独立缩放，不能据此比较真实船长或比例。

全部图片由 OpenAI 内置图片生成工具制作。开场构图与终端界面参考了太空游戏和 NASA 朋克视觉语言；此处不含游戏原始截图、商标、项目正文或玩家资料。

界面显示时可使用 `raw.githubusercontent.com` 的原图链接；固定到提交版本可避免未来替换图片影响旧界面。
